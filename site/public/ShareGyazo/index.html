ShareGyazo プライバシーポリシー

最終更新日: 2026年11月11日

English version below

ShareGyazo（以下「本アプリ」）は、利用者の個人情報や利用状況を収集しません。解析・広告・トラッキングの仕組みも含まれていません。開発者が運営するサーバとの通信は、Gyazo へのログインと imgur のトークン更新のための中継（後述）だけです。

1. 収集する情報

本アプリは、利用者の個人情報や利用状況を開発者に送信しません。アクセス解析、クラッシュレポート、広告 SDK などは一切使用していません。ログインの中継（第3項）を除き、開発者が運営するサーバと通信することはありません。

2. 画像の送信先

本アプリは、利用者が共有メニューなどから明示的に選んだ画像だけを、利用者がプロファイルに設定したアップロード先サーバ（初期設定では Gyazo、その他 imgur や利用者自身が運用するサーバなど）へ送信します。送信の前に、画像は端末内で縮小・再エンコードされます。

プロファイルに認証用のトークン（Bearer トークン）を設定した場合、そのトークンは画像と一緒に、そのプロファイルのアップロード先サーバにのみ送信されます。

送信された画像の取り扱いは、各アップロード先サービスの利用規約・プライバシーポリシーに従います。例: Gyazo、imgur。

3. ログインの中継サーバ

標準プロファイル「Gyazo」「imgur」は、各サービスの API を使い、利用者がログインしたアカウントに画像をアップロードします。Gyazo ではログイン時の認可コードをアクセストークンに交換する処理に、imgur ではアクセストークンを更新する処理に、アプリの秘密鍵（クライアントシークレット）が必要です。秘密鍵をアプリに含めずに済むよう、これらの処理だけを開発者が Cloudflare 上で運営する中継サーバ（app.sickin.dev）で行います。imgur のログイン自体は、imgur から直接アプリにトークンが返されます（ログイン完了後に表示する案内ページも同じサーバから配信します）。

  • 中継サーバに送られるのは、Gyazo のログイン時に発行された認可コードとアプリがログインのたびに生成する一時的な検証用の値、および imgur のトークン更新時のリフレッシュトークンだけです。画像は中継サーバを通りません。
  • 中継サーバは受け取った値やアクセストークンを保存しません。トークンはアプリに返され、端末内にのみ保存されます。
  • 通信の際、IP アドレスなどの一般的な接続情報が Cloudflare によって処理されることがあります。これは Cloudflare のプライバシーポリシーに従います。

4. 端末内に保存する情報

  • アプリの設定（アップロード後の動作、通知の設定など）
  • サーバプロファイル（名前、アップロード先 URL、Gyazo ID、Gyazo・imgur にログインした場合のアクセストークン（imgur ではアカウント名も）、カスタムプロファイルに設定した認証用のトークン、画像形式、利用回数）

これらは端末内にのみ保存され、開発者に送信されることはありません。Android のバックアップ機能が有効な場合、OS の仕組みにより利用者の Google アカウントにバックアップされることがあります。アプリをアンインストールすると端末内のデータは削除されます。

5. 使用する権限

  • インターネット: 画像をアップロード先サーバへ送信するため
  • 通知: アップロードの進捗と結果（画像 URL）を表示するため
  • フォアグラウンドサービス: アプリを閉じてもアップロードを最後まで完了させるため

画像は共有元アプリから受け取ったものだけを読み込み、端末内のストレージ全体へのアクセス権限は要求しません。

6. 第三者への提供

本アプリは、利用者が設定したアップロード先への画像送信を除き、いかなる情報も第三者に提供しません。

7. 本ポリシーの変更

本ポリシーを変更する場合は、このページで告知します。

8. お問い合わせ

本ポリシーに関するお問い合わせは GitHub の Issues までお願いします。

ShareGyazo Privacy Policy

Last updated: November 11, 2026

ShareGyazo (“the app”) does not collect personal information or usage data, and contains no analytics, advertising or tracking. The only communication with a server operated by the developer is a relay used when you log in to Gyazo and when imgur tokens are renewed (see below).

1. Information we collect

The app does not send personal information or usage data to the developer. No analytics, crash reporting or advertising SDKs are used. Apart from the login relay (section 3), the app does not communicate with any server operated by the developer.

2. Where images are sent

The app sends only the images you explicitly choose (for example from the share menu) to the upload server configured in your profile (Gyazo by default, or imgur or a server you operate yourself). Images are resized and re-encoded on your device before upload.

If you set an authentication token (Bearer token) in a profile, it is sent only to that profile’s upload server, together with the image.

Uploaded images are handled according to the terms and privacy policy of the destination service, e.g. Gyazo or imgur.

3. Login relay

The built-in “Gyazo” and “imgur” profiles use each service’s API to upload images to the account you log in with. Gyazo requires the app’s client secret to exchange the login’s authorization code for an access token, and imgur requires it to renew an access token. To keep the secrets out of the app, only these requests are handled by a relay the developer operates on Cloudflare (app.sickin.dev). For imgur, the login itself returns the tokens to the app directly (the page shown after login is served from the same server).

  • The relay receives only the authorization code issued by Gyazo at login, a temporary verification value the app generates for each login, and, when renewing an imgur token, the refresh token. Images never pass through the relay.
  • The relay does not store these values or the access tokens. Tokens are returned to the app and stored only on your device.
  • Cloudflare may process general connection data such as your IP address, in accordance with the Cloudflare Privacy Policy.

4. Data stored on your device

  • App settings (actions after upload, notification settings, etc.)
  • Server profiles (name, upload URL, Gyazo ID, access tokens if you log in to Gyazo or imgur (and the imgur account name), or an authentication token you set in a custom profile, image format, usage count)

This data stays on your device and is never sent to the developer. If Android backup is enabled, the operating system may back it up to your Google account. Uninstalling the app deletes this data from the device.

5. Permissions

  • Internet: to send images to the upload server
  • Notifications: to show upload progress and the resulting image URL
  • Foreground service: to finish uploads even after you leave the app

The app reads only the images handed to it by the sharing app and does not request access to your device storage.

6. Sharing with third parties

Apart from sending images to the upload server you configure, the app does not share any information with third parties.

7. Changes to this policy

Any changes to this policy will be posted on this page.

8. Contact

For questions about this policy, please open an issue on GitHub.
